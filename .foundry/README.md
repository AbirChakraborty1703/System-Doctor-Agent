# .foundry Workspace

This directory stores Foundry-focused operational assets for SystemDoctor AI.

## Purpose

- Agent metadata and environment mappings
- Evaluation datasets and benchmark suites
- Evaluator definitions and rubrics
- Experiment tracking and run history
- Prompt registries and safety policies
- Trace references and report templates

## Governance

- Keep schema files in sync with manifests
- Version all prompt and evaluator changes
- Track every benchmark run in experiments and results
