# SystemDoctor AI Knowledge Base

This directory contains deterministic troubleshooting knowledge used by local agent logic.

- decision_trees: guided question flows
- troubleshooting_playbooks: structured remediation sequences
- command_catalog: command metadata and risk levels
- hardware_fault_matrix: symptom-to-hardware-fault patterns
- mappings: symptom and diagnosis mappings
- taxonomies: issue, OS, and risk taxonomies
